Utilisation : cliquez sur une œuvre. Elle s’ouvre entière sur fond sombre.
+ / − pour zoomer ; Vue entière pour revenir au cadrage initial.
Téléphone : pincez avec 2 doigts pour zoomer, glissez pour vous déplacer.
Ordinateur : molette pour zoomer, cliquez-glissez pour vous déplacer.
Croix rouge ou touche Échap pour fermer.
Clavier : + / − pour zoomer, 0 pour la vue entière, flèches pour explorer.
