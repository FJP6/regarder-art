Le zoom : prenez le temps de regarder

Un visage, un geste, une matière ou un détail discret peuvent changer notre lecture d’une œuvre.

  1. Cliquez sur l’imageL’œuvre s’ouvre en grand.
  2. Zoomez puis faites glisserExplorez librement les détails.
  3. Revenez à l’ensemble« Vue entière » permet de retrouver la composition.

Sur téléphone : pincez avec deux doigts pour zoomer, puis faites glisser l’image pour vous déplacer.

Sur ordinateur : utilisez la molette ou les boutons + / −, puis cliquez-glissez pour explorer.

La croix rouge ferme l’image ; sur ordinateur, la touche Échap fonctionne aussi.
