Base : dernière version du dépôt fjp6/regarder-art, main 032db17, 12 octobre 2026. Les changements Uccello précédents sont conservés.

INSTALLATION
1. Décompressez le ZIP.
2. Ajoutez son contenu à la racine du dépôt GitHub. Conservez le dossier assets et ses sous-dossiers.
3. Remplacez les fichiers de même nom, sans supprimer les autres fichiers du site.
4. Validez l’ajout des fichiers, puis attendez la publication GitHub Pages.

NOUVELLE PAGE : piero-della-francesca.html
